## Corrected findings

- **A saved PDF response could be contradicted by its derived result.** If response commit succeeded and the later paper projection failed, generic error handling could save a permanent failed result. The importer now propagates that storage error and reconstructs the missing projection from the committed response on retry, without another download.
- **Page errors and whitespace needed consistent extraction semantics.** A page marked `text` with an error could previously contribute to complete extraction; any page error now makes coverage partial. The helper normalizes wholly whitespace, untruncated pages to empty text, matching the archive validator. Truncation remains explicit.
- **Read completion did not establish body teardown.** A pending read may settle as cancellation starts while its underlying cancellation promise remains unresolved. The publisher now retains one cancellation promise and keeps its admission gate until that promise settles. Regression cases cover both a stalled HTTP 200 body and early HTTP 404 rejection while preserving a bounded caller response.
- **Collection needed a verified cross-store record envelope.** The collector now checks the ledger intent's digest, event ID, sequence, null job reference and admitted bindings before joining it to the worker journal. The selected worker record must match its exact ID, digest, action and job. Prior failed or stopped execution cannot be replaced by a later success-shaped observation.

- **Cached collection projections were not semantically revalidated.** Matching request identity and a self-consistent hash could return a changed manifest, scientific verdict, replication count or contradictory completion status. Recovery now checks the fixed scientific scope, admitted identities, status/summary relationship, runtime pins, replica identity, summary arithmetic and completed artifact inventory. All four independent mutation cases are rejected. These checks detect schema inconsistency; they do not authenticate a database against a hostile writer.

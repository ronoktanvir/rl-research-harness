# Evidence assessment and planning review

This slice connects investigation receipts to criterion-level research planning. Independent methods, archive and packet reviews checked the distinction between supported byte/record observations, unresolved scientific requirements and prospective actions. The reviewed functions derive from archived observations; no caller-authored criterion verdict or proposal prose becomes execution authority.

## Corrected findings

- **Known source contradictions now fail before support.** Structurally valid investigation output could contradict the source digest or base-model declaration already saved in its capture. The assessor now checks those joins and an available final adapter declaration, including adapter checks in partial receipts. Tests update self-consistent output digests so a mere checksum failure cannot conceal this defect. The shared synthetic archive fixture's model declaration was corrected to match its capture; real project evidence was not altered.
- **Partial stage references do not reconstruct missing results.** Incomplete investigations retain verified stage prefixes but have no comparison result. The assessor credits only retained checks; it does not reconstruct counts, split overlap or comparability from earlier file references. A failure at the final comparison cannot inherit success merely because both individual conditions passed their checks.
- **Earlier diagnostic requests remain actionable.** A core test initially assumed its synthetic capture produced only the three scientific requests. It also produced missing-coverage diagnostics. The test now distinguishes those categories, and the planner retains every original non-scientific diagnostic, including requests whose priority is evidence collection.
- **Derived citations identify their actual content.** Derived packet summaries initially paired a ledger-observation locator with a different, derived assessment digest. They now use `derived-assessment:<digest>`, the rules version and a content digest, while retaining exact source observation references and pointers. Prior diagnostic findings cite their original observations.
- **Planning approval has a distinct meaning.** The previous capture-only packet had unavailable evaluation/comparison checks that would block every council, even one deciding which evidence to obtain. The new packet checks derivation and planning scope, while scientific unknowns remain explicit evidence and reviewer requirements. This does not change or pass the previous scientific checks. A synthetic approving council retains the fixed no-execution and unassessed-science declarations.

## Persistence and qualification

Archive tests check exact workflow/task/attempt/result joins, outer-versus-inner digests, conflicting IDs, missing completion, lost append acknowledgements and rehashed projection changes. Initial archival consults the queue; replay verifies a saved controller completion witness and the complete evidence chain without queue or source files. An arbitrary trusted-ledger writer remains outside the claimed integrity boundary.

Twenty focused assessment, independent, packet and archive tests passed, along with typecheck and whitespace checks. The existing cross-process CLI fixture was extended through `evidence-update`, `evidence-status` and `evidence-packet` using synthetic data and the actual parser. It verifies one immutable update, exact recovery after source deletion, equal-output reuse, conflicting-output refusal and unchanged queue tasks, invocation consumption and resource holds. Opening the ledger legitimately changes its owner epoch; that ownership effect is not mislabeled as an experiment or authority change.

The reviews preserve adverse producer counts, explicit failure accounting, the single trained-policy replication unit, and the distinction between saved runtime/schema declarations and complete evaluator identity. There is no statistical significance estimate, semantic rescoring, live council or training authorization in this slice. Actual project qualification is recorded separately in [the evidence-planning qualification](../research/evidence-planning-qualification.md).
